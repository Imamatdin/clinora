## Delivered behavior

- Registrar screen (uz-Cyrl / uz-Latn / ru, 360 px and desktop): one search box, large result cards, "New patient" form with district/mahalla/source pick lists and a phone number pad, "Who does the patient see?" with today's queue length per point and priced services, "Print tickets".
- Search: patient number (exact), last 4+ phone digits (suffix), name in any script. `registration_fold()` (migration 015) folds Cyrillic/Latin/Russian spellings (x/h/kh, q/k, oʻ/o, gʻ/g, ye/e, ts/s); every query word must match.
- Duplicate warning on same phone or same folded name + birth date; registrar picks the existing patient or proceeds with a reason (stored in `patient_duplicate_overrides`, never in audit).
- Visit creation in the open business day: one ticket per point via `nextQueueNumber`, ordered charge lines priced by `priceAt`, `patient_assignments` for every routed doctor. Patient numbers via `nextPatientNo`.
- Name edits write `full_name` and `display_name` together; stale revision -> 409.
- Server-rendered 80 mm ticket page (readable at 58 mm), auto-opens print: clinic, point, number, patient number, date/time. No name, services or diagnosis.
- Queue API for C6: `GET queue/mine`, `POST queue/call-next`, `POST queue/tickets/:id/status` (incl. called -> waiting missed call).
- Every mutation: zod schema, roles rechecked in the action, idempotency key, audit in the same transaction. Contract table: `src/modules/registration/README.md`.

## Decisions and changes

- Shared edits (one line or type widening each): route index, web module registry (registrar placeholders for search/tickets removed: delivered by this screen), uz-Cyrl parts, `style.css` import; `html?: string` on route results (`routes/types.ts`, `clinic-routes.ts`, `notebook.ts` ApiResult, `app.ts`) so tickets are served as HTML under the unchanged CSP; `ticket.css`/`ticket.js` added to the fixed public-file list because the CSP forbids inline style/script.
- Required on registration: full name, birth date, gender. Phone, address, district, source optional (children often share a parent's phone, which will also trigger the duplicate warning by design).
- Only doctor points grant patient access; lab/department points do not. Unpriced or not-offered services reject the whole visit.
- Tickets of a closed day are invisible to the queue API and immutable through it.
