## Decisions and changes

- The `core.*` i18n move is by file, not by renaming keys. Renaming every key would have touched every web file that 003C and 004 also edit.
- `patients.patient_no` and `full_name` are NOT NULL, filled by an insert trigger, so the notebook and demo paths keep working. `patient_no` is frozen after insert.
- Doctor specialty columns are `specialty_uz_cyrl/_uz_latn/_ru` (the contract said "specialty names").
- Queue status also allows called→waiting (patient missed the call) and waiting→in_progress.
- `payments.idempotency_key` length 8-200; `receipts` other than invoices need `payment_id`; dispense rows need visit and charge line.
- Repo helpers take `tx` first (the brief listed them without it). They must run inside the caller's transaction.
