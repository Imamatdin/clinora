## Decisions and changes (cross-module fixes, each with a test)
1. Registration could only create outpatient visits, so nobody could be admitted through the UI. Registrar can tick "Стационарга ётқизилади" (visit type inpatient; online only). Test: `tests/integration/task017.test.ts` (admission), clinic-day spec.
2. Admit form offered beds of every department; the server refused the mismatch with a generic error. Beds now follow the chosen department. Test: clinic-day spec.
3. Surgery required picking the surgeon and typing a time; a doctor's own entry failed (FORBIDDEN/future time across time zones). Defaults: signed-in doctor, now. Test: clinic-day spec.
4. Registration preselected the cheapest consultation (repeat visit) for new patients. New patient: full consultation; returning: the cheaper one. Test: clinic-day spec (exact bill 183 000).
5. Cashier showed "Saved" on load; keypad erase button was icon-only (⌫); totals now have test ids. Test: role-homes spec.
6. Lab: orders of closed days vanished from the lab list and could not be confirmed. Migration `023_lab_late_confirmation.sql`: completion posts to the open day (`charge_lines.completed_business_day_id`, audit keeps the visit date); with no day open it waits in `lab_pending_confirmations` and posts when the next day opens (`business-days.openDay` calls the lab hook). Line value and the closed snapshot are never rewritten (value already counted on the visit day; posting it again would double-bill). Reversible if the planner wants revenue on the posting day. Test: `task017.test.ts`.
7. Doctor ward rounds: `GET doctor/inpatients`, `POST doctor/admissions/:id/open` (attending doctor only, patient scope rechecked). Test: `task017.test.ts` (other doctor 404, ward staff 403), clinic-day spec.
- Shared seed `src/server/demo-staff.ts` (db:demo and tests); `src/server/demo-day.ts`. Removed `src/web/notebook.tsx` and its browser spec; the notebook API and its integration tests stay. Assistant and reports browser tests now use the header switch.
