## Delivered behavior
- **Header (below 900 px):** one row with the logo, the business-day badge and a "Menu" button. The menu holds the clinic name, the language switch, the user name, "PIN and Telegram", sign out, and on shared PCs "Switch user". Escape or a tap outside closes it. A hidden copy of the row measures each tab, so the split follows the language and the width. If even the current tab plus "More" is too wide (ru at 360 px), the labels wrap instead of overflowing. From 900 px the row wraps onto a second line and nothing is hidden, so desktop users see every tab.
- **CEO breakdowns:** one row per item (name and amount), largest first. The top 3 show, then an "All N doctors / departments / sources" button. Department chips (`#name`, "All" by default) filter the doctors. Tapping a row expands patients, service value, discounts and debt in place; the ↗ button still opens the ledger. The "—" doctor row reads "No doctor (ordered at registration)", and the "—" department row reads "Department not specified".
- **Source labels:** the five codes are translated, an unknown code shows "Other", and a missing source shows "Not specified". All in uz-Cyrl, uz-Latn and ru.
- **Lab card:** a doctor's order reads "Ordering doctor: X". A non-doctor's order reads "Ordered at registration: X, Registrar" (the role is translated).
- **One look:** the CEO screens use the teal palette. The CEO-only shell colour overrides are gone. The layout is unchanged apart from tighter spacing on phones.
- **CEO dashboard height at 390×844 (demo day, `scripts/demo.mjs`): 6,597 px before, 2,720 px after (about 3.2 screens).** The header is 239 px before and 65 px after, on every role.

## Decisions
- Server field (item 2): each doctor `Group` gets `departmentId/department` from `doctor_profiles`. With no profile, it uses the department with the most of that doctor's service value. It is computed before `capReport`, so the cap doesn't affect it. Day-close snapshots stored earlier don't have it; those doctors show only under "All".
- Lab `orderedByRole` is the creator's **current** clinic role (doctor first), not the role they had when they ordered. If a role was later removed, the label can change.
- Department names in the chips use `name_uz_cyrl`, the same as the existing department breakdown.
- Changed: `src/web/{shell.tsx (new),main.tsx,style.css,lab/screen.tsx,ceo/dashboard.tsx,ceo/style.css}`, i18n core/ceo/lab ×3, `src/modules/reports/{actions,records}.ts`, `src/modules/lab/actions.ts`, tests below.
